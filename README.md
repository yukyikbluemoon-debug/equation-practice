# ห้องฝึกสมการ ม.1–ม.6

เว็บฝึกโจทย์สมการ เศษส่วน เลขยกกำลัง ลอการิทึม แยกตามชั้น ม.1–ม.6 ทำชุดละ 5 ข้อ ใช้บนมือถือเป็นหลัก ไม่มีระบบล็อกอิน เก็บข้อมูลในเครื่องของเด็กเท่านั้น

## ขึ้น GitHub Pages
1. อัปโหลดไฟล์ `dist/index.html` ไปไว้ที่รากของ repo (หรือเปลี่ยนชื่อเป็น `index.html`)
2. Settings > Pages > เลือก branch `main` และโฟลเดอร์ `/ (root)`
3. ส่งลิงก์ให้เด็กเปิดด้วย Chrome หรือ Safari (ถ้าเปิดจาก LINE ข้อมูลที่เซฟไว้อาจหาย)

## วิธีทำงาน
- โจทย์ชุดวันนี้ได้จากรหัส `ชั้น-วันที่-ลำดับชุด` เช่น `2-20261025-1` รหัสเดิมได้โจทย์เดิมเสมอ จึงปิดเปิดเบราว์เซอร์แล้วโจทย์ไม่เปลี่ยน
- สร้างโจทย์แบบเลือกคำตอบก่อนแล้วสร้างสมการจากคำตอบ จากนั้นตรวจซ้ำด้วยเศษส่วนจริง (ไม่ใช้ทศนิยม) และลองแทนจำนวนตรรกยะ 5 พันกว่าค่า ต้องมีคำตอบตรงกับที่เก็บไว้พอดี
- คะแนนนับจากการตรวจครั้งแรกของแต่ละข้อ
- เซฟอัตโนมัติทุกครั้งที่ตอบ ทำจบแล้วระบบล้างเซฟของชุดนั้น แต่เก็บใบคะแนนล่าสุดและประวัติไว้

## โครงไฟล์
- `src/engine.js` เศษส่วนแบบเป๊ะ ตัวสุ่ม ตัวตรวจโจทย์และคำตอบ
- `src/gens-a.js`, `src/gens-b.js` แม่แบบโจทย์
- `src/pools.js` หัวข้อรายชั้นและการจัดชุด 5 ข้อ (ง่าย 2, ปานกลาง 2, ท้าทาย 1) แก้หัวข้อของแต่ละชั้นที่นี่
- `src/app.js`, `src/style.css` หน้าจอ
- `test.js` ทดสอบ: `node test.js` (สุ่ม 3,000 ชุด ตรวจทุกข้อ) เพิ่ม `--show --steps` เพื่อดูตัวอย่างโจทย์และวิธีทำ
- `build.py` รวมเป็นไฟล์เดียว: `python3 build.py` ได้ `dist/index.html`

## เพิ่มแม่แบบโจทย์
เพิ่มฟังก์ชันใน `src/gens-*.js` ที่คืนค่า `{topic, ask, pre, eq, ans, hint, steps, verify}` โดย `verify(x)` ต้องตรวจจากสมการเดิมด้วยเศษส่วนจริง แล้วใส่ไว้ใน `src/pools.js` จากนั้นรัน `node test.js` ก่อนอัปโหลดทุกครั้ง
